# 小小东设计原则

> 这份文档是 xxd-ui-kit 的审美宪法。每个组件、每条 token、每个 lint 规则都要能回到这里找到依据。
> 来源（按权重）：小小东写给会员站的设计规则（2026-09-26）、会员站的 `DESIGN.md`、
> `xPoster/DESIGN.md` 和 `src/xxd-theme.css`、两个站点的 `.impeccable.md`。
> 原项目里写明的规则照搬；带「提议」标记的是本项目新补的，需要你确认。

---

## 1. 气质

- **精确、克制、实用、靠判断力。** 像出版物控制台，不像营销页，也不像玩具工具。
- **克制的编辑式粗野主义**：纸色背景、清晰的黑线、干净的无衬线字、密但好读的中文、单色调色板。
- **不要**：夸张、噱头、泛泛的 AI 未来感、霓虹暗色仪表盘、渐变卡片、超大 landing 构图、卡片套卡片、设置清单、装饰性仪表盘、超大标题、隐藏的后果。
- 为每天反复使用设计，而不是为一次性 onboarding。

## 2. 颜色

- **黑 / 白 / 灰。强调靠墨色，不靠颜色。** 颜色只留给意义（成功、危险、警告）和可选的「主色」。
- 绿色只表示「已完成 / 已应用 / 成功」。
- 暗色是**暖黑**（`#171612` / `#201f1a`），不是蓝黑或纯黑。
- **主色**是一个颜色定整个界面的调子：强调用它，选中/hover 用它的淡层，背景和线条掺 3–12% 的它，让灰色同调。正文、纸、语义色不变。主色会被自动提亮或加深，保证标记 ≥ 3:1、文字 ≥ 4.5:1（亮暗两种纸上、选中底上都成立）。上面放字的实心底（主按钮、实心徽标、勾选框）用单独的 `--action-fill`：把原色压暗一点，直到白字 ≥ 4.5:1（18 个预设最多压暗 22%）；开关、tab 下划线、焦点这些标记仍是原色。18 个预设，墨色是第一个也是默认。
- 文字对比度：小字至少 4.5:1（所以 muted 是 `#6b6b6b` 而不是 `#777`；放在选中底、wash-strong 上也要 4.5）。`--muted-2` 只做装饰（图标、分隔点、行号），不当文字色。
- 系统要求更高对比度（`prefers-contrast: more`）时，控件边框加深到 3:1、次要文字到 6:1；Windows 高对比模式（`forced-colors`）下，选中、勾选、进度都用系统色重画，选中态有不靠颜色深浅的描边。平时保持安静的发丝线。

## 3. 圆角：直角 / 圆角两态

- **默认直角。** 会员站是硬规则：对话框、卡片、按钮、输入框、图标背景都不许圆角（`border-radius: 0`）。
- 插件里可以在「外观」设置里切成圆角：`<html data-corners="rounded">`。
- 圆角刻度只有五档：`--r-xs` 4px（小标记）、`--r-sm` 6px（控件）、`--r-md` 10px（面）、`--r-lg` 14px（大面）、`--r-pill`（状态标签、开关）。
- **直角模式下开关也是方的。**
- **语义上的圆永远是圆**：状态点、色块、头像、收藏/开源角标。它们用 `--r-circle`，不跟开关走。
- 所有矩形圆角都只能通过这五个 token 取值，不许写死数字。
- 是否允许某个产品**锁死**直角（会员站）或锁死圆角，由产品决定，组件库只提供开关。

## 4. 线

线是有意图的。空间先分隔；只有空间做不到时才画线。

- 线只出现在：列表行之间、tab 的基线、dock 的上沿、输入框自己的边框。
- **永远不出现两条中间什么都没有的线**：tab 下面不再画标题线；主 tab 下面不再紧跟一条全宽线。
- sheet 里的分组靠间距和小标题分，不靠上下两条横线；列表只在行**之间**画细线，第一行上面、最后一行下面都不画。
- 一组选项是一个列表，不是一叠盒子；一格符号是裸字符，hover 时才填色。
- **一个框只有一个框**：输入框聚焦时边框变深一次就够（外面不加光圈，里面不加内框）；分段控件是一个托盘，选中的那段像纸一样浮出来，不是框里套框；选中行是一层淡色（radio 已经说明选了哪个），不是淡色 + 彩色边 + 竖条。
- 浮层保留一条安静的边（`--line`），因为阴影已经把它托起来了。

## 5. 阴影与层次

- 卡片、行、按钮**没有阴影**。实心按钮可以开「质感」（`data-finish="material"`）：顶部 1px 内高光 + 深一点的边 + 按下下沉 0.5px ——
  这是材质，不是浮起；是否默认开启在展示站并排比较后决定（D1）。
- 只有浮层有阴影：tooltip、菜单、toast、对话框、dock sheet（`--shadow-popover` / `--shadow-dialog`）。
- 设置组 = 一个灰色小标题 + 一个带框的主体，里面的行用细线分开。整个 tab 外面不画框。
- 下拉选择是「一个值 + 一个 chevron」，不是一个盒子。
- tab 是基线上的文字，当前项下面一条短墨线滑过去。

## 6. 字体

- 只用系统里已有的**无衬线**字体，不用宋体 / 衬线，不加载网络字体。标题 `--font-title` 和正文 `--font-body` 是同一家族，层级只靠字号和字重。
- 先英文字体再中文字体：英文是 Avenir Next（macOS）/ Segoe UI（Windows），中文是苹方 / 微软雅黑 / 思源黑体。繁体页面（`lang="zh-Hant"`）换成苹方 TC / 微软正黑体。
- **字重只用 400 / 500 / 600。**
- 选中状态用颜色和底色表示，**不加粗**（加粗会让布局跳）。
- **相关的字靠得更近**：标题和它的说明之间的距离，要小于这一组和下一组之间的距离。
- 文字周围的垂直间距略小于水平间距（光学对齐）；不改字距。
- **换行要像排过版**：最后一行不只剩一个字；标题几行长短均匀；数字和单位、短链接、代码名不拆开；按钮、标签、tab 的字永远一行、不贴边。
  放不下时让按钮整体换到下一行、让表格横向滚动，而不是把字挤窄。（门禁：`pnpm --filter @xxd/site run audit` 的「细节」一项）
- 行内等宽字缩到约 0.9em；图标与多行文字的第一行对齐。
- 导航 13px / 500；菜单 12px / 500；移动端侧栏标签 10px。tooltip 11px。
- 阅读列宽 680px（或 70ch）；工具条、dock 可以全宽，被阅读的东西居中成一列。

## 7. 图标

- 一个家族：24 单位网格，`stroke-width` 1.5，圆头（round caps），**斜接角（miter joins）**，不填充。
- **直线和方角**，坐标落在半像素上（3.5, 20.5）；**不要** Lucide 的圆角矩形和转角弧线。只有东西本身是圆的才画圆（时钟、播放、放大镜）。
- 尺寸：12px（小字旁的 chevron）、14px（与文字同行）、16px（按钮和控件内）、18px（工具栏）、20px（侧栏）。更大只用于插画。
- 激活态改颜色/填充，**永远不改线宽**。
- 品牌标志、用户作品、头像、图表 SVG 保留自己的画法。

## 7½. 同心圆角

- 两层边框 / 底色相距 8px 以内时，圆角要同心：**外圆角 = 内圆角 + 间距**（`.xxd-concentric`）。直角模式下自然都是 0。

## 8. 动效

- 动效用来揭示层级和给反馈，不是装饰。像一次有引导的走查：细微、有目的、快、有触感。
- **只动 opacity 和 transform。不弹跳、不弹性、不霓虹、不粒子。**
- 四档速度：quick 140ms（状态变化）、medium 220ms（小型进入）、sheet 200ms 升起 / 120ms 收回（ease-out-expo）。
- **hover：进入立即变，离开 140ms 淡回**（2026-10-12 决定 D2）。快的交互带过渡会显得迟钝。
- **菜单、popover、tooltip、下拉列表从锚点方向长出来**：0.96 → 1 + 淡入 140ms，收回 100ms；对话框和 sheet 保持升起（D4）。
  tooltip 关掉后 300ms 内移到下一个按钮，立即出现、原地换字。
- 折叠展开只淡入 + 小位移，不做高度动画（D3）。
- 进行中的按钮宽度不跳：文字保留但透明，转圈居中；完成后图标变勾 1 秒。
- sheet 从 dock 升起 10px 并淡入；切 tab 是原地短淡入（东西不移动，部件不逐个进场）。
- 减少动效：一次性全部静止，没有组件例外；内容始终可见。

## 9. 交互结构

- **任务优先。** 每个设计选择都要强化清晰、信任和行动。
- 状态可见但不吵：进度、警告、限额、页面就绪都要清楚。
- 偏好可撤销的操作和清晰的恢复路径。
- **反馈就地出现**：在右侧面板里做的操作，toast 出现在面板里，不盖住主内容区。
- **底部 dock 是紧凑的任务控制台**，不是第二条导航：上下文和实时状态在开头，可撤销的选择工具成一组，后果最大的下一步在末尾。破坏性操作单独放、写清楚，不能只靠图标或颜色。
- **按钮文字描述下一次点击会做什么。** 切换按钮带 `aria-pressed`。
- 忙碌状态由一个 render 函数从应用状态反映；请求中禁用冲突控件；部分失败保留可重试的选择。
- 每个设置 URL 自己就是完整任务面，不需要第二次点击才能看到主要控件。

## 10. 对话框的按钮层级

- 取消、关闭、返回、「稍后」是**辅助操作**：用 `ui-dialog-cancel`，内容宽度、视觉安静：不 flex-grow、不等宽、不撑满整行、不用实心主色/危险色。
- 取消在 DOM/tab 顺序上**放在主操作前面**，让主操作成为最后/最右的那个承诺。窄屏上主操作可以占剩余宽度、可以换行，但取消始终是内容宽度。
- 最小点击区 40px（粗指针 44px），焦点可见。
- 标题栏的纯图标关闭按钮是另一种紧凑模式，不用 `ui-dialog-cancel`。
- **按行为分类，不按文字分类**：如果复用的按钮从「关闭」变成真正的另一个操作，就去掉 `ui-dialog-cancel`，换成次要操作样式。

## 11. 文案

- 直接、实用、照字面、让人安心。动作用动词；元数据只写事实。
- 设置项说明会影响谁、是否自动保存。
- 产品名用四个朴素的字说清它做什么（如「长文发布」「批量存图」「今日待办」）。
- 简体 / 繁体 / 英文三语；英文不回落到中文内容。

## 12. 无障碍与响应式

- 目标 WCAG 2.1 AA：原生 button/link、可见焦点、键盘可切换、明确的排序控件、命名的区域、save 状态用 live region。
- 没有任何交互依赖动效、hover 或拖拽。
- 侧边面板在手机上变成全宽 sheet；设置在手机上单列。
- 主题、圆角、主色在**首帧之前**生效（不闪）。

## 提议（本项目新增，待确认）

- **P1 密度两档**：`data-density="compact"` 给 Chrome 侧边栏/popup 用（控件 32px），缺省 40px 给网站。来源：xPoster 实际以 12–13px、紧凑行为主，会员站以 40px 控件为主。
- **P2 Shadow DOM 注入**：插件往第三方网页（如 X）注入的 UI 一律放进 Shadow DOM，令牌同时提供 `:host` 版本，避免和宿主页面样式互相污染。
- **P3 规则可执行**：上面能机器检查的规则（圆角只走 token、卡片无阴影、字重三档、图标线宽与 miter、对话框按钮顺序、主色对比度）都做成 lint 或测试，像会员站的 `*-contract.test.mjs` 一样当门禁。
