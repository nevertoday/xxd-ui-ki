# 行为准则 · Code of Conduct

**中文**

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)（[中文版](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/)）。简单说：

- 对人友善、尊重不同的经验和观点；批评事情，不攻击人。
- 不骚扰、不人身攻击、不发布别人的私人信息。
- 维护者有权删除、编辑或拒绝不符合准则的评论、提交和 issue。

遇到问题，请用 GitHub 的私密漏洞报告通道（Security → Report a vulnerability）联系维护者，标题写「行为准则」；我们会保密处理。

**English**

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be kind and respect different experiences and viewpoints; criticize ideas, not people.
- No harassment, no personal attacks, no publishing other people's private information.
- Maintainers may remove, edit or reject comments, commits and issues that don't follow this code.

To report a problem, contact the maintainers privately through GitHub's private reporting channel (Security → Report a vulnerability) with “Code of Conduct” in the title; reports are handled confidentially.
